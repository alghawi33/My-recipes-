# Future Updates

Persistent chronological project note for future changes, decisions, deferred ideas, testing plans, publication plans, monetization decisions, and UX rules.

## Universal update rule

- Update this file automatically whenever a project-relevant future feature, decision, deferred idea, UX rule, testing plan, monetization decision, or publication plan is discussed in chat. The user does **not** need to say "update the note".
- Use the current Bahrain date (`Asia/Bahrain`, UTC+3) as the heading (`YYYY-MM-DD`).
- Add multiple discussions from the same day under the same date heading. Start a new heading when the date changes.
- Preserve previous dated entries. If a decision changes, mark the old item as **Superseded** or **Cancelled** instead of silently deleting history.
- Keep entries concise but specific enough that the project can be resumed even if chat history is lost.
- Use statuses where useful: **Planned**, **Deferred**, **Testing**, **Confirmed**, **Superseded**, **Cancelled**.
